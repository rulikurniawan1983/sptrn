# SPARTAN Deployment Automation

## Setup Instructions

### 1. Laravel Cloud Deploy Hook

1. Login to [Laravel Cloud](https://cloud.laravel.com)
2. Go to your project → **Settings** → **Deploy**
3. Copy the **Deploy Hook URL**
4. Add it as a GitHub secret:
   - Go to your GitHub repo → **Settings** → **Secrets and variables** → **Actions**
   - Add secret: `LARAVEL_CLOUD_DEPLOY_HOOK` = URL from Laravel Cloud

### 2. SSH Access (Optional - for automated post-deployment)

If you want GitHub Actions to automatically run deployment commands on the server:

1. Get your Laravel Cloud server SSH details:
   - Server IP/Hostname
   - SSH Username (usually `ubuntu` or `root`)
   - SSH Port (usually `22`)

2. Generate SSH key pair (if you don't have one):
   ```bash
   ssh-keygen -t ed25519 -C "deploy@spartan" -f laravel_cloud_key
   ```

3. Add the public key to your Laravel Cloud server:
   ```bash
   ssh-copy-id -i laravel_cloud_key.pub user@your-server-ip
   ```

4. Add the private key as a GitHub secret:
   - Secret name: `LARAVEL_CLOUD_SSH_KEY`
   - Value: Contents of `laravel_cloud_key` file

5. Add server details as GitHub secrets:
   - `LARAVEL_CLOUD_SSH_HOST` = your-server-ip
   - `LARAVEL_CLOUD_SSH_USER` = username

### 3. How It Works

When you push to `main` branch:

1. GitHub Actions triggers the Laravel Cloud deploy hook
2. Laravel Cloud pulls the latest code and deploys
3. After 90 seconds, GitHub Actions SSHes into the server (if configured)
4. Runs post-deployment commands:
   - Generate APP_KEY
   - Install Composer dependencies
   - Run database migrations
   - Seed database (optional)
   - Create storage link
   - Optimize application (config/route/view/event cache)
   - Set proper permissions

### 4. Manual Deployment

If you prefer to run deployment manually:

**On Laravel Cloud server:**
```bash
cd /home/sites/default
./deploy-server.sh
```

**On Windows local:**
```bash
deploy.bat
```

### 5. Files

- `.github/workflows/laravel-cloud.yml` - GitHub Actions workflow
- `deploy.sh` - Linux/Mac deployment script
- `deploy.bat` - Windows deployment script
- `deploy-server.sh` - Server-side post-deployment script

### 6. Environment Variables Required

Make sure your `.env` file on Laravel Cloud has:

- `APP_KEY` - Generated by `php artisan key:generate`
- `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` - MySQL credentials
- `REDIS_HOST`, `REDIS_PASSWORD`, `REDIS_PORT` - Redis credentials
- `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD` - SMTP credentials
- `APP_URL` - Your production domain
- `SESSION_DOMAIN` - Your production domain

### 7. First Time Setup

On first deployment to Laravel Cloud:

1. Salin `.env.local` ke `.env` di server
2. Isi semua production credentials
3. Jalankan `php artisan key:generate`
4. Jalankan `php artisan migrate --force`
5. Jalankan `php artisan storage:link`
6. Jalankan `php artisan config:cache`

Setiap push ke `main` akan otomatis deploy!

## VS Code Workflow

### Available Tasks

Open VS Code Terminal (`Ctrl+Shift+``) and run tasks with **Terminal → Run Task** or use keyboard shortcut `Ctrl+Shift+B` for default task:

| Task | Description |
|------|-------------|
| **Start Development Server** | Runs `php artisan serve` on `http://127.0.0.1:8000` |
| **Generate APP_KEY** | Shows new APP_KEY to copy into `.env` |
| **Run Migrations** | Runs `php artisan migrate --force` |
| **Clear All Caches** | Runs `php artisan optimize:clear` |
| **Build Production Assets** | Runs `npm run build` |
| **Install Dependencies** | Runs `composer install --no-dev --optimize-autoloader` |
| **Optimize for Production** | Runs config/route/view/event cache |
| **Deploy to GitHub** | Runs `git push origin main` |
| **Commit and Push to GitHub** | Interactive commit + push |
| **Full Production Deployment** | Build + optimize + commit + push in one step |

### Recommended VS Code Extensions

Install the recommended extensions when prompted, or install manually:

- **Laravel Blade Snippets** - `onecentenhancer.php-code-sniffer`
- **Intelephense** - `bmewburn.vscode-intelephense-client`
- **PHP Debug** - `xdebug.php-debug`
- **Laravel Pint** - `laravel.pint`
- **Prettier** - `amiral.js-prettier`

### Development vs Production Workflow

#### Development (Local)
- Use **Start Development Server** task
- Uses `.env` with local settings (SQLite, Mailhog, etc.)
- Debug mode is ON (`APP_DEBUG=true`)
- Hot reload with `npm run dev` in separate terminal

#### Production (Laravel Cloud)
- Use **Full Production Deployment** task
- This will:
  1. Build production assets
  2. Install dependencies without dev packages
  3. Optimize application
  4. Commit and push to GitHub
  5. GitHub Actions triggers Laravel Cloud deployment
  6. Post-deployment scripts run automatically

### Quick Commands

```bash
# Development
npm run dev                    # Hot reload frontend
php artisan serve              # Start dev server
php artisan migrate            # Run migrations locally

# Production
npm run build                  # Build production assets
composer install --no-dev      # Install without dev dependencies
php artisan config:cache       # Cache configuration
git push origin main           # Trigger deployment
```

### Environment Files

| File | Purpose | Git |
|------|---------|-----|
| `.env` | **Active** environment file | Ignored |
| `.env.local` | Production template | Ignored |
| `.env.example` | Reference for all variables | Committed |

**Note:** Untuk development, edit `.env`. Untuk production, salin `.env.local` ke server dan sesuaikan nilai.
